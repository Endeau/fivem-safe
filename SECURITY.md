# Sécurité / Security

## Signaler une faille

Vous avez trouvé une faille dans safe_events, par exemple un appel que safe_events laisse passer alors que sa déclaration devrait le refuser ?

**Ne l'ouvrez pas en issue publique.** Utilisez le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**. Décrivez la version, la déclaration utilisée et l'appel qui passe.

Je réponds sous 7 jours. Une fois la correction publiée, le signalement est rendu public et vous êtes crédité, si vous le souhaitez.

---

## Reporting a vulnerability

Found a vulnerability in safe_events? Do not open a public issue: use GitHub private reporting (**Security** tab, **Report a vulnerability**). You will get an answer within 7 days; the advisory is published with credit once a fix is released.
